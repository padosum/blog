JavaScript ECMAScript Iterator

자바스크립트 이터레이터

PUBLISHED · 2021-12-27 UPDATED · 2023-08-24 READING · 8 min

이터레이션 프로토콜은 순회 가능한(iterable) 데이터 컬렉션(자료구조)을 만들기 위해서 ECMAScript 사양에 정의하여 미리 약속한 규칙을 말한다. ES6에 도입된 이터레이션 프로토콜은 JavaScript Symbol과 JavaScript Generator를 이해하는 가장 좋은 출발점이다.

한 줄 요약 — Symbol.iterator를 키로 갖는 메서드를 구현한 객체는 iterable이고, 그 메서드를 호출해서 얻은 { next, return?, throw? } 객체는 iterator이다.

이터레이션 프로토콜

iterable은 Well-known Symbol인 Symbol.iterator를 프로퍼티 키로 사용한 메서드를 구현하거나 프로토타입 체인을 통해 상속받은 객체를 말한다.

Iterable

const iterable = {
  [Symbol.iterator]() {
    let i = 0;
    return {
      next() {
        return i < 3
          ? { value: i++, done: false }
          : { value: undefined, done: true };
      }
    };
  }
};

for (const v of iterable) console.log(v); // 0, 1, 2

위 코드는 iterable이 곧 iterator가 아니라는 점을 보여준다. Symbol.iterator()를 호출해야 비로소 이터레이터가 만들어진다.

빌트인 이터러블

JavaScript의 빌트인 객체 중 다음은 이터러블이다 — Array, String, Map, Set, TypedArray, arguments, NodeList.

  • 일반 객체(Object)는 이터러블이 아니다.
  • 그래서 for...of가 동작하지 않고, spread도 키 순회가 안 된다.
  • 이터러블로 만들고 싶다면 Symbol.iterator 메서드를 직접 구현하면 된다.

왜 알아야 하는가

이터레이션 프로토콜을 이해하면 JavaScript Generator를 자연스럽게 받아들일 수 있고, 함수형 라이브러리의 lazy evaluation이 왜 메모리 효율적인지 한 줄로 설명할 수 있다.
